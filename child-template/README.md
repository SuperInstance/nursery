# Child template

Copy `CHILD.md` to `children/<your-child-name>/CHILD.md` and fill it in.

Your child's code goes in the same directory. Build on the zero core
(`~/workspace/jev-ideation/zero-core.py`) — don't fork it, harness it.

```
children/<your-child-name>/
  CHILD.md        # this template, filled in
  <your-code>.py  # your harness — the decisions in code
  dogfeed.log     # raw log from your dogfeed sessions
```

That's it. No build system. No config. The CHILD.md is the child.
